EBER MARTINI — SITIO WEB

Estructura:
- index.html
- css/styles.css
- js/main.js
- assets/video/eber-martini-hero.mp4
- assets/img/logo-eber-martini.svg
- assets/img/video-poster.jpg
- assets/img/look-01.jpg a look-04.jpg

Cómo abrir:
1. Abrí esta carpeta en Visual Studio Code.
2. Usá la extensión Live Server sobre index.html.
3. También podés abrir index.html directamente, aunque Live Server es recomendable.

Personalización rápida:
- Textos: index.html
- Colores: variables al inicio de css/styles.css
- Enlaces de Instagram: buscar "eber_hairstylistsalon" en index.html y js/main.js
- Logo: reemplazar assets/img/logo-eber-martini.svg conservando el mismo nombre.

Formulario:
La versión entregada prepara el mensaje, lo copia al portapapeles y abre Instagram.
Para envío automático real puede conectarse a Formspree, WhatsApp Business o un backend propio.

Video:
Se creó a partir del video enviado, recortando las franjas negras y el bloque de Instagram.
Se exportó en H.264, 1280x720, sin audio y con faststart para web.
